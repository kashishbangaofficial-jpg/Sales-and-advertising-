# 📘 Simple Linear Regression Project

## 📌 Project Overview

This project demonstrates the implementation of a **Simple Linear Regression Model** using Python and Scikit-learn. The program reads data from an Excel dataset, trains a regression model, evaluates its performance, and visualizes the regression line with actual data points.

The model automatically selects the first numeric column as the **independent variable (X)** and the second numeric column as the **dependent variable (y)** from the dataset.

---

## 🚀 Features

* Load dataset from an Excel file (`Data.xlsx`)
* Automatically detect numeric columns
* Split dataset into training and testing sets
* Train a Simple Linear Regression model
* Predict test data values
* Evaluate model using:

  * Mean Squared Error (MSE)
  * R² Score
* Visualize regression results using Matplotlib
